## Format Standard (applies to ALL 15 articles)

### Position tier system
| Tier | Position | Format | Description length | CTA count | Logo |
|------|---------|--------|--------------------|-----------|------|
| Exclusive | Top 1 | Full section (H2) | 200–250w | 3–4 | Yes |
| Featured | Top 2–3 | Subsection (H3) | 100–120w | 1–2 | Optional |
| Listed | 4–10 | List item (H4/bullet) | 40–60w | 1 | No |
| Mention | 11+ | Name + 1 line | 10–20w | 0 | No |

### Required elements every article
- [ ] Quick comparison table (above fold, before first H2)
- [ ] Methodology / how we tested section (E-E-A-T signal)
- [ ] FAQ section minimum 5 questions (AI Overview + PAA bait)
- [ ] Internal links: minimum 3 to related articles in batch
- [ ] Meta title: keyword front-loaded, under 60 chars
- [ ] Meta description: 150–160 chars, includes keyword + differentiator hook
- [ ] Schema: ItemList (every article) + FAQPage (every article)
- [ ] Disclaimer: risk/financial disclaimer above fold for casino and investment articles
